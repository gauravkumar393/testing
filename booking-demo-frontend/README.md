# booking-demo

Mock booking engine prototype (search → choose room → guest details → confirm),
built with React + Vite + Tailwind. All data in `src/BookingEngine.jsx` is
static/mock — no API calls, no real payment, no real PMS connection.

## Run it

```
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Build for production

```
npm run build
npm run preview
```
